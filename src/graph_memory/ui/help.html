Sessions Knowledge

Before each reply, knowledge recall may show Claude a few notes learned in earlier sessions. After the reply, memory checks which notes the reply used: it has to share enough distinctive words with a note, or be very close to it in meaning. That means the reply dealt with the same thing, not that the note changed the answer. On a sample of turns a model also reads the prompt, the reply and the notes, and judges each note useful, neutral or misleading, and whether the reply shows it wrong (contradicted: the note is disputed, and retracted if it happens again). Turns that showed a note which could have gone stale (a tool's behaviour, a latest version) are always judged.
